> Converter tool to convert Arcanum assets to OpenArcanum new format

## Installation

```sh
$ npm install --save open-arcanum-asset-converter
```

## Usage

npm start OR

```js
const executor = require('@openarcanum/asset-converter').executor;

executor.start(arcanumPath, outputPath);
```
