# open-arcanum-asset-converter [![NPM version][npm-image]][npm-url] [![Build Status][travis-image]][travis-url] [![Dependency Status][daviddm-image]][daviddm-url]
> Converter tool to convert Arcanum assets to OpenArcanum new format

## Installation

```sh
$ npm install --save open-arcanum-asset-converter
```

## Usage

```js
const openArcanumAssetConverter = require('open-arcanum-asset-converter');

openArcanumAssetConverter('Rainbow');
```
