# OpenArcanum UI scripts

This directory retains the authored GUI definitions from the old asset database.
The original/converted game assets, fonts, movies, archives and rule tables are
not distributed. Place your locally prepared data outside this directory and
configure `OPENARCANUM_DATA_PATH` or the root `config.json`.

These scripts are work in progress. See the root README and DEVELOPMENT guide.
The source scripts are GPL-3.0-or-later; see the root LICENSE.
