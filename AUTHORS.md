## Historical Git attribution

For this publication, the author and committer fields of all imported project
commits were normalized to Gabriel Max <dev@zetta.app>, as requested by the
maintainer. This metadata normalization does not establish sole authorship or
remove contributors' copyright or license notices.

snapshot and **Tomster** on the generated Ember scaffold. Those labels are
preserved in `Historical-Author` commit-message trailers. They describe the
available Git records; they are not independent confirmation of who wrote each
file in a snapshot. Sylwester's recorded attribution is preserved in the same way.
